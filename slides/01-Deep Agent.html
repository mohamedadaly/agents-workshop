3 · SYSTEM PROMPT

Steering the Agent

Passed as system_prompt=INSTRUCTIONS — four rules keep the ReAct loop safe and on-task:

Look before you query

Verify table names with sql_db_list_tables, inspect schemas with sql_db_schema first.

Check before you run

Run non-trivial queries through sql_db_query_checker before sql_db_query.

Read-only, always

No INSERT, UPDATE, DELETE, DROP — ever.

Plan multi-step work

Use the agent’s built-in todo list before a multi-step question.

4 · SYSTEM PROMPT

The Prompt, Verbatim

You are an agent designed to interact with a SQL database.

Given an input question, create a syntactically correct sqlite query, run it, inspect the results, and return a concise answer. Unless the user asks for a specific number of rows, limit results to at most 10. Never SELECT * — only request the columns you need.

Do NOT issue any DML statements (INSERT, UPDATE, DELETE, DROP, etc.).

Always verify table names with sql_db_list_tables and inspect schemas with sql_db_schema before writing a query. Use sql_db_query_checker on any non-trivial query before running it with sql_db_query.

For multi-step questions, use your todo list to plan the steps before you start querying.

Use duckduckgo_search only for questions that need outside/current information the database can’t answer. Prefer the SQL tools whenever the question is about the data itself.

Answer in plain language. Do not describe the database schema or the steps you took.

1 · ORIGIN

Why It Was Invented

Two 2022-era approaches each got half the job done:

Reasoning-only (Chain-of-Thought)

Great at step-by-step logic, but frozen in time — no way to look anything up, so it confidently hallucinates facts it can’t know.

Acting-only agents

Can call tools, but act impulsively — no visible plan, hard to debug, and errors compound with no reflection.

ReAct (Yao et al., 2022) interleaves both: reasoning steers which action to take next, and each action’s result corrects the reasoning.

4 · PAYOFF

Why It Matters

Grounded

The agent checks the real schema instead of guessing a column name — fewer hallucinated facts.

Interpretable

Every thought, action, and observation is a message you can read — literally the trajectory expander.

Recoverable

A bad query doesn’t fail silently — the next loop iteration can look again and correct course.

Extensible

Deep agents layer planning and sub-agents on top of this same Thought → Action → Observation core.
